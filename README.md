# MellShop — контрольная работа №4

Тема — JavaScript, DOM, события, формы и валидация. Основа перенесена из КР №3 на чистом HTML и CSS.

## Практика №15

На главной и в каталоге подключены `js/data.js` и `js/main.js`. Атрибут `defer` откладывает выполнение до разбора HTML и сохраняет порядок скриптов: сначала данные, затем работа с ними.

`data.js` хранит объект товара. В `main.js` функции форматируют цену, считают сумму скидки и итоговую цену, определяют наличие и собирают описание. `return` возвращает результат для дальнейшего использования. Console показывает входной объект и результаты функций.

Учебный блок на главной выводит описание через `textContent`. Это свойство вставляет строку как текст. `innerHTML` разбирает строку как разметку, поэтому его нельзя применять напрямую к пользовательским данным. Например, строка `<b>Шелли</b>` через `textContent` отображается вместе с угловыми скобками.

## Проверка

- Открыть index.html и Console. Для Шелли ожидаются цена 2000 руб., скидка 300 руб., итог 1700 руб. и статус «В наличии».
- Открыть catalog.html. Результаты видны в Console, учебный блок находится на главной.
- На главной открыть «Заказать» и закрыть модальное окно через Esc.

## Малые опыты

Открыть lab.html и Console. Исходные прогнозы по порядку: заголовок меняется, количество становится 2, тип цены — number. Для строк получаем 1100/true, NaN/false и 0/false. Ветка скидки показывает 900. Функция возвращает 400 и 500.

Повторить опыты с изменениями: поменять заголовок в basics.js, установить цену строкой, попробовать недоступный товар и скидку 0, поменять процент с 20 на 25 (ожидается 375). Временно заменить return на console.log и проверить undefined в Console. После опытов вернуть исходные значения. Для диагностики ошибки пути можно временно указать отсутствующий файл скрипта в lab.html, открыть Console и восстановить путь.
