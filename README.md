## Практика №15

На главной и в каталоге подключены `js/data.js` и `js/main.js`. Атрибут `defer` откладывает выполнение до разбора HTML и сохраняет порядок скриптов: сначала данные, затем работа с ними.

`data.js` в практике №15 хранил один объект товара. В `main.js` функции форматируют цену, считают сумму скидки и итоговую цену, определяют наличие и собирают описание. `return` возвращает результат для дальнейшего использования. Console показывает входной объект и результаты функций.

На учебном этапе блок на главной выводил описание через `textContent`. В финальном проекте этот пример доступен в `lab.html`. Свойство `textContent` показывает строку `<b>Шелли</b>` вместе с угловыми скобками. `innerHTML` разобрал бы её как разметку.

## Практика №16

Массив `products` содержит восемь игрушек с уникальными `id`, категориями, числовыми ценами и сведениями о наличии. Для двух товаров со скидкой процент вычислен из старой цены и суммы скидки, чтобы итог совпадал с карточкой. Учебные функции сортировки, расчёта суммы и средней цены используют поле `price` с ценой до скидки.

- map собирает названия, filter отбирает товары, find возвращает первый товар с нужным id.
- sort меняет порядок элементов в копии массива, поэтому исходный порядок сохраняется.
- reduce считает сумму цен. Средняя цена пустого списка равна 0.
- getPreparedProducts последовательно применяет поиск, категорию и сортировку.

В `lab.html` сводка выводится через `textContent`, а результаты всех функций доступны в Console. На этапе №16 карточки ещё были статичными.

Для опытов в Console возьми [100, 200, 300]. Спрогнозируй результаты map со скидкой 10, filter с порогом 200, find с условием больше 150 и reduce с начальной суммой 0. Ожидаются [90, 190, 290], [200, 300], 200 и 600. Для сортировки возьми [30, 5, 12] и сравни результат сортировки копии с исходным массивом. У forEach callback вызывается для каждого элемента, метод возвращает undefined.

## Практика №17

Каталог строит карточки из массива через createElement и textContent. Поиск, категория и сортировка обновляют список без перезагрузки. Сортировка каталога использует цену после скидки. Общий обработчик контейнера принимает клики по кнопкам «В корзину» и определяет товар по его id.

На странице заявки JavaScript выводит ошибки имени, e-mail и телефона рядом с полями. Товар, доставка и согласие проверяются браузером. При успехе показывается сообщение о прохождении проверки.

Для отладки в Chrome открой Sources → catalog.js и поставь точку останова на строке с productsContainer.replaceChildren внутри updateCatalog. Введи «кот» и посмотри catalogState и preparedProducts. F8 продолжит выполнение.

## Практика №18 и самостоятельные доработки

- `js/catalog.js` обновляет каталог и передаёт выбранный id в корзину.
- `js/cart.js` добавляет и удаляет товары, меняет количество и сохраняет массив пар id/quantity в localStorage под ключом mellshop-cart-v1. Цены берутся из data.js при каждом расчёте.
- Корзина выводит состав, сумму товаров, скидку и итог. Сумма считается через `reduce`. Расчёт в копейках сохраняет денежную точность.
- Промокод `MELL10` даёт 10% от суммы после скидок на товары. Корзина передаёт применённый код в форму заявки. При новой загрузке корзины код нужно ввести снова.
- По ссылке «Заказать» в каталоге форма сразу выбирает нужную игрушку. По ссылке «Оформить заявку» из корзины форма показывает все выбранные товары, количество и итоговую стоимость товаров.
- `js/validation.js` проверяет форму заявки. После успешной проверки очищает поля и показывает сообщение. Учебная форма работает в браузере, корзина остаётся в `localStorage`.
